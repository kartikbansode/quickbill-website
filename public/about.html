ABOUT QUICKBILL

About QuickBill

QuickBill is a professional desktop billing and point-of-sale system designed for retail shops and small businesses.

What is QuickBill?

QuickBill is a professional desktop billing and POS management system. It provides a complete billing workflow with barcode scanning, product and inventory management, payments, invoice generation, billing history, and optional customer-facing display synchronization.

The project is built around a Windows desktop application that serves as the central billing system, with optional Android companion applications for barcode input and customer-facing display.

Project Purpose

QuickBill is designed to bring common retail billing and POS operations into a single desktop application. It addresses the practical needs of managing:

  • Products and pricing
  • Inventory and stock information
  • Cart and billing state
  • Transactions and payments
  • Customer information
  • Professional invoices
  • Billing history and reprints

The desktop application is intended for everyday point-of-sale use in retail shops and small businesses.

QuickBill Desktop

QuickBill Desktop is the core application. It is the authoritative source of billing and payment state.

The desktop application manages:

  • Products
  • Inventory
  • Cart state
  • Bills
  • Transactions
  • Payment state
  • Customer information
  • Invoice generation

It provides the main billing and POS workflow, including manual and barcode-based item entry, tax and discount handling, hold and resume, bill history, and communication with companion applications.

QuickBill Ecosystem

The QuickBill ecosystem consists of three applications:

01 — QuickBill Desktop

Platform: Windows 10 / Windows 11
Role: Core billing and POS application · Source of truth

Responsibilities include billing, products, inventory, cart, transactions, payments, customer information, invoices, billing history, and communication with companion applications.

Repository →

02 — QuickBill Barcode Scanner

Platform: Android 8.0+
Role: Input companion

Companion Android application that provides barcode-scanning functionality for QuickBill Desktop. It turns a phone into a dedicated barcode scanner and network camera for the desktop application. It is not an independent billing system.

Repository →

03 — QuickBill Customer Display

Platform: Android 8.0+ (tablet)
Role: Customer-facing display companion

Companion Android application that provides a real-time customer-facing display for current bill items, quantities, prices, totals, payment information, UPI QR, and payment success state. It receives and displays state from QuickBill Desktop; it does not calculate or modify the bill. The desktop remains fully functional if the display is disconnected.

Architecture

QuickBill Desktop is the central application. Companion applications provide specialized input and customer-facing display support.

QuickBill Desktop Windows · Core billing & POS · Source of truth
Barcode Scanner Android · Input companion
Customer Display Android · Customer-facing display

Billing authority stays inside the desktop application. Companion applications do not replace the desktop system and do not become the source of truth for billing or payment state.

Platform Support

QuickBill Desktop is designed for Windows desktop environments:

  • Windows 10
  • Windows 11

Packaged Windows installers do not require a separate Python installation. Running from source requires Python 3.11 or newer and the packages listed in requirements.txt.

Companion applications target Android 8.0 (API 26) or higher and require the same local network as the desktop computer.

Payments & UPI

QuickBill supports Cash, UPI, Card, and Credit payment workflows.

For UPI, QuickBill can generate a dynamic payment QR containing:

  • UPI ID
  • Merchant name
  • Current bill amount
  • Bill number
  • Currency

Security guidance: Do not place UPI PIN, password, bank credentials, or other sensitive information in the source code. Use a valid business or merchant UPI ID, and test with a small transaction before live billing. Full configuration steps are in the Documentation.

Invoice System

QuickBill generates professional PDF invoices with support for:

  • A4 invoice format
  • 80 mm receipt format
  • Printable billing documents
  • Automatic bill numbering
  • Bill reprinting from history

Design Approach

QuickBill keeps billing authority inside the desktop application while companion applications provide specialized input and customer-facing functionality. This separation ensures that:

  • The desktop remains the single source of truth for bills and payments
  • Companion apps can disconnect without interrupting billing
  • Retail workflows stay practical and operator-focused
  • Customer-facing information stays synchronized with the desktop state
