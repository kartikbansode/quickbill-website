QuickBill v3.1.0

14 August 2026 · Current Stable

CURRENT STABLE

Version 3.1.0 is a focused configuration, personalization, stability, and production-readiness update for QuickBill. This release adds application-level business and payment configuration while improving deployment consistency and fixing several production-related issues.

New Application Settings

  • Added UPI ID configuration directly inside Settings
  • UPI ID can now be changed without editing source code
  • Added Cashier Name setting
  • Added Company / Business Name setting
  • Added Owner Name setting
  • Added Business Address setting
  • Added Business Phone setting
  • Added Business Email setting
  • Added GST Number setting
  • Settings are stored locally on the user's computer
  • Configured values persist after application restart

Invoice Personalization

  • Configured business information is now used automatically in generated invoices
  • Cashier information can be reflected in invoices
  • Business identity information can be reflected in invoices
  • Updated 80 mm invoice information handling
  • Updated A4 invoice information handling
  • Added sensible QuickBill defaults when optional business fields are left empty

UPI Configuration Improvements

  • Removed the need to modify the UPI ID directly in application source code
  • UPI configuration is now managed through the application Settings
  • Configured UPI ID persists between application sessions
  • Improved handling of user-specific UPI configuration

Bug Fixes & Stability

  • Fixed application startup and splash-screen initialization issues
  • Improved startup sequencing to prevent the main window and splash screen from launching incorrectly
  • Improved handling of customer display initialization failures
  • Improved compatibility handling for customer display WebSocket dependencies
  • Improved local configuration persistence
  • Fixed production build configuration issues
  • Removed developer-specific dependency paths from the production build configuration
  • Improved application behavior across different Windows computers

Production & Release Updates

  • Updated application version metadata to v3.1.0
  • Updated executable version information to v3.1.0
  • Updated installer metadata to v3.1.0
  • Updated PyInstaller production configuration
  • Updated installer configuration for the v3.1.0 release
  • Updated project copyright and ownership information
  • Removed remaining Essenc Technologies branding from the production release
  • Updated project documentation and release information

Release Status

QuickBill v3.1.0 is the current stable release and includes the latest configuration improvements, personalization features, production fixes, and release packaging updates.
