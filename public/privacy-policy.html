1. Introduction

This Privacy Policy applies to the official QuickBill website (the “Website”), which provides project information, documentation, release history, and links to software downloads for the QuickBill desktop billing and POS system and its companion applications.

QuickBill follows a data-minimization approach: the Website is designed so that ordinary browsing, documentation access, and use of public download links do not require users to create accounts or submit personal information.

2. Scope

This Policy covers information processed in connection with the Website under QuickBill’s control.

This Policy does not automatically govern:

  • GitHub or other third-party platforms linked from the Website
  • External websites that QuickBill does not control
  • Local data stored or processed by the QuickBill Desktop application or companion applications on a user’s own devices, unless that data is separately transmitted to the Website (which the current Website design does not do)

Third parties have their own privacy practices. Please review those practices when you leave the Website.

3. Information We Collect

Information intentionally requested

The Website does not intentionally request personal information for ordinary browsing, viewing documentation, or accessing public download links. There is no account registration, login, newsletter form, or contact form on the Website as currently implemented.

Technical information processed by infrastructure

When you visit the Website, standard web request information may be processed automatically by the hosting, network, or security infrastructure that serves the site. Depending on the hosting and security configuration, this may include items such as:

  • IP address
  • Browser and device type information
  • Requested URL or resource
  • Date and time of the request
  • Referring page (if provided by the browser)
  • Security or operational event logs

QuickBill does not operate a separate intentional “visitor profile” system on the Website. Technical request information, where processed, is typically used for delivering the site, maintaining security, and diagnosing technical issues, as handled by the infrastructure provider.

4. Information We Do Not Intentionally Collect

Based on the current Website implementation, QuickBill does not intentionally collect through the Website:

  • Name, phone number, or postal address
  • Aadhaar, PAN, or other government identification numbers
  • Bank account details, credit/debit card numbers, or UPI PIN
  • Passwords or authentication credentials for the Website
  • Biometric data
  • Merchant transaction records, bills, or customer purchase history from QuickBill Desktop
  • Contacts, device files, camera data, microphone data, or GPS location data

If you choose to contact the project author through an external channel (for example, LinkedIn or GitHub), that channel’s own practices apply.

5. How Information Is Used

Where technical request or security information is processed by hosting or infrastructure services, it is used for purposes such as:

  • Delivering the Website and its content
  • Maintaining availability and performance
  • Detecting and mitigating abuse, fraud, or security threats
  • Diagnosing errors and supporting the operation of the site

QuickBill does not use Website visitor information for behavioral advertising or for building marketing profiles of individual visitors, based on the current implementation.

6. Cookies and Similar Technologies

QuickBill does not intentionally deploy cookies on the Website for advertising, behavioral profiling, or third-party analytics tracking.

Hosting, content delivery, or security infrastructure may set technical cookies or similar technologies that are necessary to operate or secure the site. Those technologies are controlled by the relevant infrastructure provider under its own terms and privacy practices.

7. Analytics and Advertising

The Website does not currently use third-party analytics services (such as Google Analytics) to build behavioral profiles of visitors.

The Website does not currently display third-party behavioral advertising.

If analytics, advertising, or similar tools are added in the future, this Policy will be updated to describe them before or when they are introduced.

8. Hosting and Infrastructure

The Website is intended to be served using standard web hosting and, where applicable, content delivery and security infrastructure. Such infrastructure may process technical request and security information as part of providing hosting, CDN, and network security services.

If Cloudflare or a similar provider is used for hosting, CDN, or security, that provider may process technical information under its own privacy policy and as a service provider supporting the operation of the Website. QuickBill remains responsible for its own privacy practices described in this Policy.

For Cloudflare’s current privacy information, see: Cloudflare Privacy Policy .

9. Third-Party Services

The following third-party services are relevant to the Website as currently designed:

  • GitHub — source repositories, release assets, and project pages linked from the Website. GitHub is an independent platform. When you visit GitHub, GitHub’s terms and privacy policy apply. GitHub Privacy Statement
  • Hosting / CDN / security infrastructure — may process technical request and security information as described in Section 8.

The Website does not currently embed third-party analytics, advertising networks, social media tracking pixels, or similar tracking scripts.

10. GitHub and External Links

The Website contains links to GitHub repositories, release pages, and other external sites (including LinkedIn). These sites are not controlled by QuickBill.

When you follow an external link, the destination site’s own privacy policy and terms apply. QuickBill is not responsible for the privacy practices of external websites it does not control.

11. Software Downloads

Download links on the Website typically point to GitHub Releases or other public distribution pages. Download requests may therefore be handled by GitHub’s infrastructure.

QuickBill does not receive personal information solely because a user clicks a public download link on the Website, beyond any technical request information processed by the Website’s own hosting infrastructure and by the download host (e.g. GitHub).

12. QuickBill Desktop vs Website Data

QuickBill Desktop is a local Windows application. Product, inventory, bill, transaction, and related data used in the desktop application are stored and processed locally as part of the application’s design (local application storage).

The Website does not automatically receive:

  • Bills or invoice content from QuickBill Desktop
  • Customer records entered in the desktop application
  • Inventory or product catalogues from the desktop application
  • Payment or UPI configuration details from a user’s installation

Using the Website and using QuickBill Desktop are separate activities. Installing or running the desktop application does not, by itself, transmit billing data to the Website under the current project design.

13. Data Sharing

QuickBill does not sell, rent, or trade personal data for monetary consideration.

Information may be disclosed where reasonably necessary for:

  • Compliance with applicable law or lawful requests from authorities
  • Protecting security, integrity, or rights of the project or users
  • Operation of the Website through infrastructure or service providers (for example, hosting or security providers processing technical request information)

QuickBill does not share Website visitor information with advertisers for behavioral targeting under the current implementation.

14. Data Retention

QuickBill does not intentionally retain personal profiles of Website visitors for marketing or advertising purposes.

Technical request or security logs, where generated by hosting or infrastructure providers, are retained according to those providers’ practices and only as long as reasonably necessary for security, operations, and legal obligations.

Information is not retained longer than needed for the purposes described in this Policy or required by applicable law.

15. Data Security

Reasonable technical and organizational measures are used to protect information under QuickBill’s control, consistent with the nature of a public documentation and download website.

Where the Website is served over HTTPS, transport between the user’s browser and the hosting infrastructure is encrypted in transit.

No method of transmission or storage is completely secure. QuickBill does not claim that the Website is free from all risk of unauthorized access or disruption.

16. Security Incidents

If QuickBill becomes aware of a security incident affecting personal data under its control, it will assess the incident and take reasonable steps consistent with applicable law, which may include notifying affected individuals and/or the relevant authority where required.

17. Data Principal Rights

Under the Digital Personal Data Protection Act, 2023 (DPDP Act), individuals (Data Principals) may have rights in relation to their personal data, including where applicable:

  • Right to access information about personal data
  • Right to correction, completion, updating, and erasure
  • Right of grievance redressal
  • Right to nominate another person to exercise rights in the event of death or incapacity

Because the Website does not intentionally collect personal data for accounts or forms, many rights requests may simply confirm that QuickBill does not hold personal data about the requester beyond any technical logs held by infrastructure providers.

Rights may be subject to conditions and exceptions under applicable law. QuickBill will respond to valid requests in accordance with the DPDP Act and rules made thereunder, to the extent they apply.

18. Grievance Redressal

If you have a privacy-related concern or request regarding the Website, please contact the project using the channels listed in Section 22 (Contact).

QuickBill will review the request or complaint and respond as reasonably practicable. Under the DPDP Act, Data Principals generally should exhaust the opportunity of redressing a grievance with the Data Fiduciary before approaching the Data Protection Board of India, where applicable.

No separate Data Protection Officer or formal grievance officer has been designated solely for this Website beyond the project contact channels described in this Policy.

19. Children

The Website is intended for general users of a professional software project (documentation, downloads, and project information). It is not directed at children as a primary audience.

Please do not submit personal information relating to children through external contact channels unless you are authorized to do so and the processing is permitted under applicable law.

20. International Access

The project is based in India. The Website may be accessible from outside India. Applicable obligations depend on the user’s jurisdiction and on QuickBill’s activities.

This Policy is written with reference to Indian law, including the DPDP Act, 2023. It does not claim compliance with every foreign privacy regime (for example, the GDPR) unless separately assessed and stated.

21. Changes to This Policy

This Privacy Policy may be updated when:

  • Website functionality changes
  • Data processing practices change
  • Legal requirements change
  • Third-party services used by the Website change

The “Last updated” date at the top of this page will be revised when material changes are made. Continued use of the Website after an update constitutes notice of the revised Policy, except where applicable law requires additional notice or consent.
