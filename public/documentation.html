Getting Started

QuickBill is a professional desktop billing and point-of-sale system designed for retail shops and small businesses. It provides a complete billing workflow with barcode scanning, product and inventory management, payments, invoice generation, billing history, and optional customer-facing display synchronization.

The current stable release is QuickBill v3.1.0 .

Start by reviewing the system requirements, then install either a packaged release or run the application from source.

Requirements

QuickBill Desktop

  • Windows 10 or Windows 11
  • Python 3.11 or newer (required only when running from source)
  • Required Python packages listed in requirements.txt (source installation)

Technology stack

  • Desktop application: Python
  • GUI framework: Tkinter
  • Invoice generation: PDF
  • Product and billing data: local application storage
  • Packaging: PyInstaller
  • Platform: Windows 10 / Windows 11

Companion applications

  • QuickBill Customer Display: Android tablet, Android 8.0 (API 26) or newer, same local network as the desktop
  • QuickBill Barcode Scanner: Android device with camera, Android 8.0 (API 26) or higher, same local network as the desktop

Installation

Packaged Windows release

Official release files are published on the GitHub Releases page. Where a Windows setup installer is published for a given version, download and run the installer, then launch QuickBill from the Start Menu or desktop shortcut.

Packaged installers do not require a separate Python installation on the target machine.

See the Downloads page for links to the current and previous releases.

First run

After launching QuickBill Desktop:

  1. Open product management and add your products.
  2. Configure UPI settings if you intend to use UPI payments (see UPI Configuration).
  3. Create your first bill from the billing screen.
  4. Optionally connect the Customer Display and/or Barcode Scanner companion applications on the same local network.

Running from Source

To run QuickBill Desktop from source on a development machine: 

git clone https://github.com/kartikbansode/quickbill.git
cd quickbill
pip install -r requirements.txt
python app.py

Requires Python 3.11 or newer and the packages listed in requirements.txt.

Building QuickBill

To build a packaged executable with PyInstaller:

Ecosystem Overview

QuickBill consists of a core desktop application and optional companion applications:

  • QuickBill Desktop — the core Windows billing and POS application. It is the authoritative source of billing data and manages products, inventory, cart state, bills, transactions, payments, customer information, and invoice generation.
  • QuickBill Customer Display — companion Android application that provides a real-time customer-facing display for bill items, totals, payment information, UPI QR display, and payment success state.
  • QuickBill Barcode Scanner — companion Android application that provides barcode-scanning functionality for QuickBill Desktop.

Companion applications connect to QuickBill Desktop. The desktop remains fully functional if a companion application is disconnected.

UPI Configuration

QuickBill supports dynamic UPI QR payments. Before using UPI payments, configure your UPI ID in the following two files.

1. Configure UPI ID

Open: 

logic/upi_payment.py

Find: 

DEFAULT_UPI_ID = "PUT-YOUR-UPI-ID-HERE"

Replace it with your own UPI ID. Example: 

DEFAULT_UPI_ID = "yourupi@bank"

2. Configure Payment Dialog

Open: 

gui/payment/payment_dialog.py

Find: 

self.upi_id = "PUT-YOUR-UPI-ID-HERE"

Replace it with the same UPI ID. Example: 

self.upi_id = "yourupi@bank"

Make sure the UPI ID is identical in both files.

Dynamic UPI QR

When UPI payment is selected, QuickBill generates a dynamic payment QR containing:

  • UPI ID
  • Merchant name
  • Current bill amount
  • Bill number
  • Currency (INR)

The QR code is generated automatically for each bill and can be displayed through the customer display system.

Important security notes

  • Use a valid UPI ID belonging to the business or merchant.
  • Use the same UPI ID in both configuration locations.
  • Do not add your UPI PIN, password, bank credentials, or other sensitive information to the source code.
  • Test the generated QR code with a small transaction before using QuickBill for real billing.

Hold & Resume

QuickBill supports temporarily holding an active billing session and resuming it later without losing the current bill.

Use hold when you need to pause a sale (for example, to serve another customer) and resume when you are ready to continue the same bill.

Customer Display

QuickBill Customer Display is a companion Android application that provides a real-time customer-facing display for the QuickBill desktop billing system over a local network.

What it displays

  • Current bill items
  • Quantities, rates, and amounts
  • Subtotal, tax, discount, and total
  • Customer and cashier information
  • Payment information (Cash, UPI, Card, Credit)
  • UPI QR display
  • Payment pending and payment success screens

Architecture

QuickBill Desktop remains the authoritative source of billing and payment state. The Customer Display receives and shows desktop state and events; it does not calculate or modify the bill.

The desktop application continues to operate normally if the customer display is disconnected.

Connection

The customer display connects to QuickBill Desktop using: 

WebSocket
Port: 8765

The Android tablet and the Windows computer must be on the same local network.

Requirements

  • Android tablet
  • Android 8.0 (API 26) or newer
  • QuickBill Desktop
  • Tablet and desktop on the same local network

Reliability features

  • Real-time bill synchronization
  • Automatic reconnection
  • Graceful disconnected state
  • Full-screen tablet interface

Barcode Scanner App

QuickBill Barcode Scanner is a companion Android application designed to work with QuickBill Desktop. It provides a dedicated mobile barcode-scanning interface for scanning products and sending barcode information to the desktop application for use in billing and product workflows.

Features

  • Android camera barcode scanner
  • Real-time barcode detection
  • Network camera streaming
  • QuickBill Desktop integration
  • Automatic IP address configuration
  • Continuous scanning
  • Duplicate scan prevention
  • Camera selection
  • Scanner settings and customization

Requirements

  • Android 8.0 (API 26) or higher
  • Android device with camera
  • QuickBill Desktop
  • Android device and desktop connected to the same network

Setup

Download and install the latest APK on your Android device. Open the app and configure the scanner settings. The displayed device/network address can be configured in QuickBill Desktop under Scanner Settings.

The Android device acts as a wireless barcode scanner for the desktop billing application.

Troubleshooting

Scanner is not connecting

Confirm that the Android device and the Windows computer are on the same local network. Verify the phone IP address shown in the scanner application and check that the scanner application is running. Configure the displayed network address in QuickBill Desktop under Scanner Settings.

Customer Display is disconnected

Confirm that the Android tablet can reach the Windows computer over the local network and that QuickBill Desktop is running. The Customer Display connects using WebSocket on port 8765. The desktop remains fully functional if the display is disconnected; reconnection is automatic when the network path is restored.

UPI QR not generating or incorrect amount

Confirm that the same valid merchant UPI ID is configured in both logic/upi_payment.py and gui/payment/payment_dialog.py. Do not place UPI PIN, password, or bank credentials in the source code. Test with a small transaction before live use.

Running from source fails

Ensure Python 3.11 or newer is installed and that dependencies from requirements.txt have been installed with pip install -r requirements.txt. Run the application with python app.py from the project directory.

FAQ

What operating systems are supported?

QuickBill Desktop supports Windows 10 and Windows 11.

What Python version is required?

Python 3.11 or newer is required when running from source. Packaged Windows installers do not require a separate Python installation.

What payment methods are supported?

Cash, UPI, Card, and Credit.

What invoice formats are supported?

A4 and 80 mm PDF invoices.

What is the Customer Display?

An optional Android companion application that shows real-time bill items, totals, payment information, and UPI QR on a customer-facing screen. QuickBill Desktop remains the authoritative billing system.

What is the Barcode Scanner app?

An optional Android companion application that acts as a wireless barcode scanner for QuickBill Desktop, using the device camera and local network.

How is UPI configured?

Set the same merchant UPI ID in logic/upi_payment.py and gui/payment/payment_dialog.py. See UPI Configuration.

Where is the source repository?

https://github.com/kartikbansode/quickbill

Is the Customer Display required?

No. It is optional. QuickBill Desktop continues to operate when the display is disconnected.
