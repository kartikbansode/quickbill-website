Source Code

QuickBill source code is available on GitHub for viewing, educational, portfolio, and evaluation purposes. The project can also be run from source on a development machine.

Main repository →  ·  All GitHub releases →

To run from source (requires Python 3.11+): 

git clone https://github.com/kartikbansode/quickbill.git
cd quickbill
pip install -r requirements.txt
python app.py

To build a packaged executable with PyInstaller: 

pyinstaller QuickBill.spec

The executable will be generated inside the dist folder.

System Requirements

Supported Platform Windows 10 / Windows 11
Application Type Desktop Billing & POS
Programming Language Python
GUI Framework Tkinter
Python Runtime (source) Python 3.11+
Packaging PyInstaller

Packaged Windows setup installers do not require a separate Python installation on the target machine. Running from source requires Python 3.11 or newer and the packages listed in requirements.txt.
