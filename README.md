# QuickBill Website

Official public website for QuickBill.

QuickBill is a professional Windows billing application developed by Kartik Bansode, with companion Android applications for barcode scanning and customer display.


## Repositories

- Desktop: https://github.com/kartikbansode/quickbill
- Barcode Scanner: https://github.com/kartikbansode/quickbill-barcode-scanner-app
- Customer Display: https://github.com/kartikbansode/quickbill-customer-display-app
